# k8s-pods-viewer v1.6.0

`k8s-pods-viewer` v1.6.0 turns the provider-aware node metadata added in v1.5.0
into a dedicated platform node panel beside the pod list, and adds an optional
cluster running-cost tile that prices the visible nodes with live AWS on-demand
and spot rates.

## Highlights

- added a platform node metadata panel to the sidebar, titled for the detected
  platform (`EKS Nodes`, `GKE Nodes`, `AKS Nodes`, or `Node Fleet` on unmanaged
  clusters)
- the panel draws a column only when at least one node has a value for it, so
  EKS clusters show instance type, capacity type, zone, and nodegroup while a
  `kind` or bare-metal cluster falls back to os/arch and kubelet
- added cluster-wide rollups under the node table for nodegroup, capacity type,
  instance type, zone, and kubelet distribution
- `i` (detailed info) adds the EC2/VM machine ID column plus region, arch,
  AMI/image, OS image, and container runtime rollups
- the panel gives up its rollup before trimming node rows when the sidebar runs
  short of vertical space, and reports the remainder as `+N more nodes`
- Karpenter nodes now report the cloud they actually run on when the node
  `providerID` says which one, so a Karpenter node on AWS reads as `EKS`
- normalized EKS `ON_DEMAND` capacity to the `on-demand` wording used in the UI
- added a `Cluster Cost` tile beside `Cluster Memory` showing the summed hourly
  price of the visible nodes plus a monthly projection (`hourly × 730`)
- on-demand prices come from the AWS Pricing API (`GetProducts`), matched on
  instance type, region, OS, shared tenancy, and used capacity status
- spot nodes are priced from the most recent EC2 spot price for their exact
  availability zone (`DescribeSpotPriceHistory`), falling back to the on-demand
  rate until a sample arrives
- prices are fetched in the background, cached in memory, and never block the
  render loop; on-demand refreshes every 12 hours, spot every 10 minutes
- added `--cost` and `cost=<bool>` config support; the tile and all AWS calls
  are off by default

## Notes

- the node metadata panel reads only Kubernetes node objects, so no AWS, GCP,
  or Azure credentials are needed for it
- cost is opt-in: without `--cost` (or `cost=true`) no pricing provider is
  wired up, no AWS API calls are made, and the tile is not rendered
- cost needs read-only `pricing:GetProducts` and `ec2:DescribeSpotPriceHistory`
  with the local credentials, honoring `--aws-profile`; when credentials or
  permissions are missing the tile shows `n/a` with a short reason
- only AWS-backed nodes are priced; other platforms show
  `n/a · no priced platform` rather than sending unknown instance types to the
  AWS Pricing API
- the tile covers node compute only: control-plane fees, EBS volumes, load
  balancers, snapshots, and data transfer are not included
- added `github.com/aws/aws-sdk-go-v2`, `.../config`, `.../service/ec2`, and
  `.../service/pricing` as direct dependencies
- bumped `k8s.io/api`, `k8s.io/apimachinery`, `k8s.io/client-go`, and
  `k8s.io/metrics` from 0.36.1 to 0.37.0
