# k8s-pods-viewer v1.6.1

`k8s-pods-viewer` v1.6.1 is a patch release fixing kubeconfig path-list parsing,
subprocess kubectl execution with compound kubeconfig files, pod health evaluation
for completed init containers, node tracking stability, and dependency security fixes.

## Highlights

- **Kubeconfig Path Lists**: `--kubeconfig` path lists now parse with the operating
  system list separator via `filepath.SplitList`, fixing path splitting on Windows
  (`C:\...;...`) and standard multi-file lists (`/path/a:/path/b`).
- **Child Kubectl Execution**: Subprocess kubectl commands (`logs`, `describe`,
  `exec`, `kill`, `scale`) now pass the configured kubeconfig via the `KUBECONFIG`
  environment variable instead of `--kubeconfig`, avoiding flag errors when
  multiple kubeconfig paths are provided.
- **Init Container Pod Health**: Pods with successfully completed init containers
  (exit code 0) are no longer marked as unhealthy; failed init containers continue
  to report as critical.
- **Node Identity Consistency**: Keyed nodes by node name instead of provider ID,
  preventing nodes whose provider ID is populated after registration from
  becoming stale or undeletable.
- **Security & Dependency Updates**: Bumped `golang.org/x/net` to `v0.62.0` (fixing
  `GO-2026-6866` and `GO-2026-6860`), `k8s.io/*` dependencies to `v0.37.2`,
  `github.com/charmbracelet/x/ansi` to `v0.11.9`, and AWS SDK v2 dependencies to `v1.47.6`.
- **Developer Tooling & CI**: Added `//go:build ignore` to standalone scripts in
  `hack/` to resolve duplicate main collisions in workspace tooling, updated
  `Makefile` license checks for GOPATH binary discovery, and upgraded release and
  test GitHub Actions workflows.
