# k8s-pods-viewer v1.4.2

`k8s-pods-viewer` v1.4.2 adds explicit AWS profile selection for users who
access EKS clusters with named AWS CLI profiles.

## Highlights

- added `--aws-profile <name>` to select a named AWS profile, such as `alex`
- added `AWS_PROFILE` environment variable support
- added `aws-profile=<name>` support in `~/.k8s-pods-viewer`
- the selected profile is used by both kubeconfig exec authentication and
  pod actions that invoke `kubectl`
- documented AWS profile usage and added release flag coverage

## Release Validation

This release was validated with:

- automated Go tests via `go test ./pkg/... ./cmd/...`
- race detection via `go test -race ./pkg/... ./cmd/...`
- release smoke checks via `make test-release`
- static analysis via `go vet ./pkg/... ./cmd/...`
- local binary build verification via `make build`

## Notes

- AWS profile selection controls authentication only; Kubernetes RBAC still
  determines which namespaces, pods, nodes, and metrics the user can access
- CLI flags override environment variables, which override config file values
- existing behavior is unchanged when no AWS profile is specified
